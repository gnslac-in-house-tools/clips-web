# clips-web
Skill `app-preview-clip` portable para Claude Code web.
1. Sube este repo a GitHub (privado: incluye el logo de Gensler).
2. En claude.ai/code conecta el repo y, en el entorno, permite acceso a red (npm, Playwright y la app a grabar).
3. Abre sesión y pide: «hazme un clip de preview de <app>».
Notas: la skill completa de demo con voz (`app-demo-video`) NO está incluida; solo su motor en `engine/`.
